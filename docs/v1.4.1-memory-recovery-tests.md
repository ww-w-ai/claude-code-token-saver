### Critical issues
- **Q11 edge case (memory-test request)**: The user's next request that *triggered* the auto-compact is recorded at L1733 as a `type: "last-prompt"` metadata record. Although MAX_LINE=1733 is inclusive, preprocess.js does not recognize the `last-prompt` type and skips it, so this message never appears in compact.txt. This is NOT a cutoff off-by-one.
- **Cutoff off-by-one verified (Part 2 finding)**: Inspection of session 2545efef at lines 1732–1734:
  - L1732 = `type: "user"` tool_result (ordinary user turn)
  - L1733 = `type: "last-prompt"` (CC's metadata snapshot of the prompt that triggered compact)
  - L1734 = `type: "system", subtype: "compact_boundary"` (the compact event itself)
  - MAX_LINE = `lastContextLossLine - 1` = 1733 **correctly includes L1733** — the cutoff is not off-by-one. The Q11 gap is caused by preprocess.js not rendering `last-prompt` records, which is a separate enhancement opportunity (future work: teach preprocess.js to emit `last-prompt` content as a pseudo user turn).

## Comparison: compact.txt vs CC Auto-Compact Summary

### compact.txt strengths
- 100% verbatim user messages (up to 500 chars, no paraphrase drift)
- Every user turn in strict chronological order
- L{n} enables surgical topic restoration via raw JSONL seek
- Zero LLM cost
- Preserves discussion-drift arcs (hypothesis → rebuttal → conclusion)

### Auto-compact summary strengths
- LLM-synthesized "Primary Intent" / "Pending Tasks" / "Current Work" sections
- Full code snippets and function signatures preserved where needed
- Collapsed false starts and redundant iterations
- More concise for "what matters" recall

### Net assessment
**Complementary, not redundant.** compact.txt is a strict superset in raw recoverability (via L{n}) but inferior in synthesis. For fast "where was I?" recovery, compact.txt alone is sufficient. For deep "exactly how did we solve this?" recovery, the auto-compact summary or a topic-targeted L{n} restore is still valuable. The Case B flow combines both: LLM summarization of the compacts plus verbatim L{n} originals for topic-matched turns.
