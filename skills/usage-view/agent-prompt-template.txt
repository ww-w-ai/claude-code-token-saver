## Cache Pricing Guide (use this knowledge when interpreting cache data)
- Cache Read: 90% cheaper than regular input (e.g. $0.50/MTok vs $5/MTok for Opus)
- Cache Write 1h tier: 100% surcharge over input (e.g. $10/MTok vs $5/MTok). 1h tier = main sessions + pipe mode (claude -p)
- Cache Write 5m tier: 25% surcharge over input (e.g. $6.25/MTok vs $5/MTok). 5m tier = subtask/subagent sessions
- High cache read = conversations are being cached and reused at discount = GOOD for cost
- BUT high cache read also means context is growing large = needs management
- The key insight: caching saves money, but context growing too large wastes it. Balance is everything.

## Natural Token Pattern for Complex Work (MUST understand before writing)
- For users doing complex coding work (not simple chat), the natural cost hierarchy is: input < output << cache_write << cache_read
- This is NORMAL and EXPECTED. Do NOT treat this as a problem or anomaly.
- Why: each turn sends the full conversation history → cache_read dominates. Output is just the AI's response per turn → much smaller.
- IMPORTANT: Cache read token COUNT ratio (e.g. "95% of tokens") is MEANINGLESS to report — it's always very high by nature. Do NOT mention cache read token count ratios.
- Instead, focus on cache read COST ratio (% of total cost). This is the meaningful metric:
  - If cache read cost ratio is 70%+ → large continuous conversation, context is growing, suggest context management
  - If cache read cost ratio is 50-60% → efficient pattern, likely using SubTasks well to keep main context small
  - If cache read cost ratio is below 50% → very efficient, or mostly SubTask-driven work
- When SubTask usage is high and cache read cost ratio is moderate (50-60%), this means the user is efficiently delegating heavy work to SubTasks, keeping main context small and saving cache costs. Frame this positively.
- The educational takeaway: since cache_read grows with context size, "context engineering" (managing what stays in context) is the key cost lever.
- When mentioning this pattern, frame it as education, not as a warning.
